# tools/tagslam/

The offline TagSLAM field-calibration tool: a factor graph over logged corners from every module plus robot odometry, which solves for the as-built tag map and camera extrinsics. It runs on a desktop and has no real-time budget. See [TagSLAM](../../docs/PLAN.md#tagslam-offline-field-calibration).

- **Filled in by:** [Stage 8](../../docs/stages/stage-8-tagslam.md).
